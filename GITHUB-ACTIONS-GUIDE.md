(9 AM UTC)\n\n### Converting Your Timezone\n\nIf 12 PM doesn't work, adjust the cron schedule:\n\n| Timezone | UTC Offset | Cron Hour | When Tests Run |\n|----------|-----------|-----------|----------------|\n| PST (Pacific) | UTC-8 | 20 | 8 PM previous day |\n| MST (Mountain) | UTC-7 | 19 | 7 PM previous day |\n| CST (Central) | UTC-6 | 18 | 6 PM previous day |\n| EST (Eastern) | UTC-5 | 17 | 5 PM previous day |\n| GMT (UK) | UTC+0 | 12 | 12 PM noon |\n| CET (Europe) | UTC+1 | 11 | 11 AM |\n| EET (Your TZ) | UTC+3 | 9 | 9 AM UTC = 12 PM local |\n| IST (India) | UTC+5:30 | 6:30 | 12 PM noon |\n| JST (Japan) | UTC+9 | 3 | 12 PM noon |\n\n### How to Change Schedule\n\n1. Edit `.github/workflows/daily-tests.yml`\n2. Find this line:\n   ```yaml\n   - cron: '0 9 * * *'\n   ```\n3. Change `9` to your desired UTC hour\n4. Commit and push\n\nExample for EST (5 PM daily):\n```yaml\n- cron: '0 17 * * *'\n```\n\n---\n\n## ✅ Testing the Workflow Manually\n\nDon't want to wait until tomorrow? Check Settings → Secrets and variables\n2. Verify all 3 secrets are created:\n   - BASE_URL\n   - TEST_USERNAME\n   - TEST_PASSWORD\n3. Make sure values are correct\n\n### Issue: \"Failed\" status with error\n\n**Cause**: Credentials wrong or site changed\n\n**Solution**:\n1. Check secret values in Settings\n2. Verify test account credentials work manually\n3. Check test logs in Actions for error details\n4. Update page object locators if UI changed\n\n### Issue: Workflow not showing up\n\n**Cause**: Workflow file syntax error\n\n**Solution**:\n1. Go to **Actions** tab\n2. Look for **Workflows** section\n3. If workflow shows error, check YAML syntax\n4. Validate at: https://www.yamllint.com/\n\n### Issue: Tests timeout\n\n**Cause**: Slow network or site performance\n\n**Solution**:\n1. Increase timeout in workflow: `timeout-minutes: 45`\n2. Check site status: https://maps.roadtrippers.com\n3. Review test logs for slow steps\n\n---\n\n## 📊 Creating a Dashboard\n\nYou can create a custom dashboard to monitor test results:\n\n### Option 1: GitHub Status Badge\n\nAdd to your README.md:\n\n```markdown\n[![Playwright Tests](https://github.com/anastasiyaSG/playwright-ts-yamasoft/actions/workflows/daily-tests.yml/badge.svg)](https://github.com/anastasiyaSG/playwright-ts-yamasoft/actions)\n```\n\nThis shows:\n- ✅ Pass/Fail status\n- Click to view details\n- Auto-updates after each run\n\n### Option 2: Set Up Notifications\n\nSlack Integration (Advanced):\n1.

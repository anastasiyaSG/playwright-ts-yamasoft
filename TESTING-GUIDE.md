are broken\n\n**Solution:**\n1. Update `.env` with correct credentials\n2. Run `npx playwright codegen https://maps.roadtrippers.com`\n3. Inspect the element and get the correct locator\n4. Update page object in `src/pages/`\n5. Re-run tests\n\n### Tests Timeout\n\n**Cause:** Slow network or element takes too long to appear\n\n**Solution:**\n```bash\n# Increase timeout in playwright.config.ts\nuse: {\n  timeout: 15000,  // 15 seconds instead of 10\n}\n```\n\n### Tests Pass Locally but Fail in CI\n\n**Common Issues:**\n- Different browser rendering\n- Network delays\n- Missing environment variables\n\n**Solution:**\n1. Run all browsers locally: `npm test`\n2. Check .env has correct credentials\n3. Test with slow network: `npx playwright test --headed` in slow 4G\n\n### Authentication Failures\n\n**Cause:** Credentials expired or UI changed\n\n**Solution:**\n1. Verify credentials in `.env` file\n2. Test login manually on https://maps.roadtrippers.com\n3. If manual login works, check LoginPage.ts locators\n4. Use `npx playwright codegen` to find new element locators\n\n---\n\n## 📝 Writing New Tests\n\n### Test Template\n\n```typescript\nimport { expect } from '@playwright/test';\nimport { test } from '../src/fixtures';\nimport { logger } from '../src/utils/logger';\n\ntest('📋 My new test', async ({ authenticatedPage, myTripsPage }) => {\n  logger.info('\\n🔄 TEST: My new test');\n  \n  const page = authenticatedPage;\n  \n  // Your test steps here\n  await page.goto('https://maps.roadtrippers.com');\n  logger.info('✅ Navigated to home');\n  \n  // Assertions\n  const heading = page.locator('h1');\n  await expect(heading).toBeVisible();\n  logger.info('✅ Heading visible');\n  \n  logger.info('✅ TEST PASSED\\n');\n});\n```\n\n### Using Page Objects\n\n```typescript\n// Access page objects from fixtures\ntest('...', async ({ tripCreationPage, myTripsPage }) => {\n  // Page objects provide methods:\n  await tripCreationPage.fillTripDetails();\n  await tripCreationPage.createTrip();\n  \n  const tripCount = await myTripsPage.getTripsCount();\n});\n```\n\n### Using Helper Functions\n\n```typescript\nimport { startTrip, fillAndCreateTrip, safeDeleteTrip } from '../src/utils/tripHelpers';\n\ntest('...', async ({ authenticatedPage, tripCreationPage }) => {\n  const page = authenticatedPage;\n  \n  // Use helpers for common workflows\n  await startTrip(page, tripCreationPage);\n  await fillAndCreateTrip(tripCreationPage);\n  \n  // ... test logic ...\n  \n  await safeDeleteTrip(page);  // Cleanup\n});\n```\n\n---\n\n## 🔐 Test Data & Credentials\n\n### Current Test Account\n```\nUsername: qa_yamasoft_assesment\nPassword: pCvw5t73YUFY!B2\nSite: https://maps.roadtrippers.com\n```\n\n### Test Data (Hardcoded)\n```typescript\n// From constants.ts\nTRIP_START: 'A',        // Arizona\nTRIP_END: 'B',          // Brooklyn\nTRIP_DATE: '10',        // 10th of current/next month\n```\n\nTo use different data:\n1. use page objects\n- Rely on timing - use Playwright waits\n- Create state dependencies between tests\n- Commit `.env` files with real credentials\n- Use `await page.waitForTimeout()` as primary wait\n- Test implementation details, test behavior\n\n---\n\n## 📞 Support\n\n**Issues?**\n1.

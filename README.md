# Roadtrippers TypeScript Playwright Test Automation\n\nA comprehensive TypeScript + Playwright test automation suite for the Roadtrippers trip planning application (maps.roadtrippers.com).\n\n## Features\n\n✅ **Page Object Model** - Clean, maintainable page abstractions\n✅ **Custom Fixtures** - Reusable authenticated and guest user setups\n✅ **Overlay Handling** - Automatic dismissal of gist, offer popups, and cookie banners\n✅ **No Sleep Calls** - Pure Playwright auto-waiting and explicit assertions\n✅ **Multi-Browser Testing** - Chromium, Firefox, WebKit support\n✅ **Comprehensive Logging** - Timestamp-prefixed console output\n\n## Test Coverage\n\n### Smoke Tests (4 tests)\n1. Guest trip creation and launch\n2. Authenticated user trip creation with persistence\n3. Authenticated user trip creation with stops\n4. Form validation - missing destination rejection\n\n### Expanded Tests (4 tests)\n1. Invalid starting point validation\n2. Trip creation without stops\n3. Trip deletion with confirmation dialog\n4. Trip persistence after browser refresh\n\n**Total: 8 tests** covering core trip creation, validation, and persistence scenarios.\n\n## Project Structure\n\n```\n.\n├── src/\n│   ├── pages/              # Page Object Models\n│   │   ├── LoginPage.ts\n│   │   ├── MyTripsPage.ts\n│   │   └── TripCreationPage.ts\n│   ├── utils/              # Helper functions & utilities\n│   │   ├── constants.ts\n│   │   ├── logger.ts\n│   │   ├── overlayHandler.ts\n│   │   └── tripHelpers.ts\n│   └── fixtures.ts         # Custom Playwright fixtures\n├── tests/\n│   ├── trip-creation.spec.ts\n│   └── trip-creation-expanded.spec.ts\n├── playwright.config.ts\n├── tsconfig.json\n├── package.json\n├── .env.example\n└── README.md\n```\n\n## Quick Start\n\n### Prerequisites\n- Node.js 16+\n- npm or yarn\n\n### Setup\n\n```bash\n# 1. Clone and navigate to repo\ngit clone https://github.com/anastasiyaSG/playwright-ts-yamasoft.git\ncd playwright-ts-yamasoft\n\n# 2. Install dependencies\nnpm install\n\n# 3. Install Playwright browsers\nnpx playwright install\n\n# 4. Create .env file\ncp .env.example .env\n\n# 5. Edit .env with your credentials\n# BASE_URL=https://maps.roadtrippers.com\n# USERNAME=your_test_username\n# PASSWORD=your_test_password\n```\n\n### Running Tests\n\n```bash\n# Run all tests\nnpm test\n\n# Run with browser visible\nnpm run test:headed\n\n# Run interactive UI mode\nnpm run test:ui\n\n# Run in debug mode\nnpm run test:debug\n\n# Run specific test file\nnpm test tests/trip-creation.spec.ts\n\n# Run tests matching pattern\nnpm test -- --grep \"Guest\"\n```\n\n### View Reports\n\n```bash\n# View HTML test report\nnpm run test:report\n```\n\n## Environment Variables\n\nCreate `.env` file from `.env.example`:\n\n```ini\nBASE_URL=https://maps.roadtrippers.com\nUSERNAME=your_test_username\nPASSWORD=your_test_password\n```\n\n## Architecture Decisions\n\n### Page Object Model\nEach page is a class with semantic locators:\n```typescript\nthis.loginButton = page.getByRole('link', { name: 'Log in' });\nthis.destinationInput = page.getByRole('textbox', { name: 'Destination' });\n```\n\n### Fixtures\nCustom fixtures extend Playwright test with:\n- Pre-instantiated page objects\n- Authenticated user setup\n- Automatic overlay dismissal\n\n### Utilities\n- `overlayHandler.ts` - Dismisses overlays\n- `tripHelpers.ts` - Reusable workflows\n- `logger.ts` - Timestamped logging\n- `constants.ts` - Centralized test data\n\n## Locator Strategy\n\n1. **Semantic locators (preferred)**\n   - `page.getByRole()` - most resilient\n   - `page.getByText()` - for visible text\n\n2. **CSS selectors (fallback)**\n   - Scoped to reduce brittleness\n\n3. **XPath (avoid)**\n\n## Debugging\n\n```bash\n# Browser DevTools with pause on first line\nnpm run test:debug\n\n# Interactive test execution with element inspection\nnpm run test:ui\n\n# Inspect elements with Playwright codegen\nnpx playwright codegen https://maps.roadtrippers.com\n```\n\n## CI/CD Ready\n\nConfiguration supports:\n- Multi-browser testing\n- Automatic retries on failure\n- HTML reporting\n- Environment-based settings\n\n## Contributing\n\n1.
